# MovieLens Web Application

Αυτή είναι μια Client-Server Web εφαρμογή που επιτρέπει στους χρήστες να εξερευνήσουν το γνωστό dataset ταινιών **MovieLens Latest Small**, να προσθέσουν νέες ταινίες, να αξιολογήσουν όσες έχουν δει, και να λάβουν προσωποποιημένες συστάσεις με βάση τον αλγόριθμο **User-Based Collaborative Filtering** (Pearson Correlation).

Η εφαρμογή αναπτύχθηκε στα πλαίσια του μαθήματος "Web Applications Development".

---

##  Δομή του Project

Το project είναι οργανωμένο σε δύο κύριους φακέλους για πλήρη διαχωρισμό του Client από τον Server:

* **`backend/`**: Περιέχει τον κώδικα του Python FastAPI server, τις ρυθμίσεις του API, και τα scripts για την αυτόματη δημιουργία της βάσης δεδομένων SQLite.
* **`frontend/`**: Περιέχει τα αρχεία της διεπαφής χρήστη (HTML, CSS, Vanilla JavaScript). Δεν χρησιμοποιούνται εξωτερικά frameworks.

---

##  Απαιτήσεις Συστήματος

* **Python 3.8** ή νεότερη έκδοση.
* Ένας σύγχρονος Web Browser (Google Chrome, Mozilla Firefox, Safari κ.λπ.).

---

## Οδηγίες Εγκατάστασης & Εκτέλεσης 

Για να τρέξετε την εφαρμογή τοπικά στον υπολογιστή σας, ακολουθήστε τα παρακάτω βήματα με τη σειρά.

### Βήμα 1: Εγκατάσταση Εξαρτήσεων (Backend)
Ανοίξτε το τερματικό (ή το Command Prompt / PowerShell), πλοηγηθείτε στον φάκελο `backend` και εγκαταστήστε τις απαραίτητες βιβλιοθήκες Python εκτελώντας την παρακάτω εντολή:

    pip install -r requirements.txt

### Βήμα 2: Προετοιμασία Βάσης Δεδομένων [cite: 130]
Πριν τρέξετε τον server, πρέπει να κατεβάσετε το dataset (αυτοματοποιημένα) και να δημιουργήσετε τη βάση δεδομένων SQLite (`movielens.db`). Παραμένοντας στον φάκελο `backend`, εκτελέστε το αντίστοιχο script:

    python setupdb.py

*(Η διαδικασία θα κατεβάσει αυτόματα το αρχείο zip από τον server του MovieLens, θα το αποσυμπιέσει στη μνήμη, και θα μεταφέρει τα δεδομένα από τα CSV αρχεία στους πίνακες της βάσης.)*

### Βήμα 3: Εκκίνηση του Backend Server
Για να ξεκινήσετε το RESTful API, βεβαιωθείτε ότι βρίσκεστε στον φάκελο `backend` και τρέξτε τον server χρησιμοποιώντας το Uvicorn:

    uvicorn main:app --port 3000 --reload

Ο server σας τώρα "ακούει" στη διεύθυνση: `http://localhost:3000`

### Βήμα 4: Εκκίνηση του Frontend
Για να χρησιμοποιήσετε την εφαρμογή, **δεν** χρειάζεται κάποιος επιπλέον server (όπως Live Server). 
Απλώς μεταβείτε στον φάκελο `frontend` και ανοίξτε το αρχείο **`index.html`** απευθείας στον browser της επιλογής σας κάνοντας διπλό κλικ πάνω του. 

*(Σημείωση: Το Backend έχει ρυθμισμένο το CORS ώστε να επιτρέπει με ασφάλεια τα αιτήματα από τα τοπικά HTML αρχεία του συστήματός σας).*

##  Βασικές Λειτουργίες

* **Προσθήκη Ταινίας:** Καταχώρηση νέου τίτλου και είδους (genres) στη βάση δεδομένων με δυναμική ανάθεση νέου ID.
* **Αναζήτηση Ταινιών:** Εύρεση ταινιών βάσει λέξης-κλειδιού στον τίτλο (case-insensitive αναζήτηση λέξεων). 
* **Αξιολόγηση (0.5 - 5):** Οι χρήστες μπορούν να βαθμολογήσουν ταινίες. Οι βαθμολογίες αποθηκεύονται προσωρινά (μόνο στη μνήμη του browser κατά τη διάρκεια του session).
* **Μέσος Όρος:** Δυνατότητα προβολής της συνολικής μέσης βαθμολογίας για οποιαδήποτε ταινία, κάνοντας κλήση σε όλα τα ιστορικά δεδομένα της βάσης.
* **Εξατομικευμένες Συστάσεις:** Παραγωγή των Top-10 συστάσεων ταινιών με πρόβλεψη βαθμολογίας, κάνοντας χρήση του Collaborative Filtering αλγορίθμου, με βάση τα ενεργά ratings του session.
